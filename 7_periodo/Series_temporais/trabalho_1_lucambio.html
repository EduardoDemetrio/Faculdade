Questão 1: Modelo de Regressão Defasada (Frozen Juice)

Este exercício analisa a relação entre as variações de preço do suco de laranja concentrado congelado e as condições climáticas (FDD - Frozen Degree Days) na Flórida.

1.1 Carga de Dados e Pré-processamento

Primeiro, carregamos os dados diretamente da fonte e realizamos as transformações necessárias para obter o índice de preços real e as variações percentuais.

library(astsa)

# Leitura dos dados
FrozenJuice <- read.csv("http://leg.ufpr.br/~lucambio/CE017/20251S/FrozenJuice.csv")

# Definição das variáveis conforme o enunciado
# FOJCPI: Índice de preços deflacionado pelo PPI
FOJCPI <- FrozenJuice[, "price"] / FrozenJuice[, "ppi"]

# FOJC_pctc: Variação percentual do preço (diff do log)
FOJC_pctc <- 100 * diff(log(FOJCPI))

# FDD: Graus-dia de congelamento mensais
FDD <- FrozenJuice[, "fdd"]

# Transformando em séries temporais (Início em Jan/1950)
fojcpi_ts <- ts(FOJCPI, start = c(1950, 1), frequency = 12)
fojc_pctc_ts <- ts(FOJC_pctc, start = c(1950, 2), frequency = 12)
fdd_ts <- ts(FDD, start = c(1950, 1), frequency = 12)

Item (b) — Estimação do Modelo de Regressão Defasada (LagReg)

A função LagReg do pacote astsa é utilizada para ajustar o modelo de regressão defasada entre a variação de preço e o índice de congelamento. Estimaremos o modelo e faremos previsões para 6 meses à frente.

# Alinhando a variação de preço com as defasagens do FDD (0 a 6 meses)
# Criamos um data frame com as defasagens
dados_reg <- ts.intersect(
  Preco = fojc_pctc_ts,
  FDD0 = fdd_ts,
  FDD1 = lag(fdd_ts, -1),
  FDD2 = lag(fdd_ts, -2),
  FDD3 = lag(fdd_ts, -3),
  FDD4 = lag(fdd_ts, -4),
  FDD5 = lag(fdd_ts, -5),
  FDD6 = lag(fdd_ts, -6)
)

# Ajuste do modelo de regressão defasada
fit <- lm(Preco ~ FDD0 + FDD1 + FDD2 + FDD3 + FDD4 + FDD5 + FDD6, data = dados_reg)

# Resumo do modelo
summary(fit)

Questão 2: Análise Dinâmica do Gene BNRF1

O objetivo desta questão é realizar uma análise de janela deslizante (sliding window) para comparar a estrutura do gene BNRF1 no vírus Epstein-Barr (EBV) e no Herpesvírus Saimiri (HVS).

2.1 Carregamento dos Dados e Pacotes

Utilizaremos o pacote astsa, que contém os dados genômicos necessários.

library(astsa)

2.2 Análise de Frequência de Nucleotídeos

Vamos converter a sequência numérica em indicadores para analisar a periodicidade de nucleotídeos específicos (como a citosina - C).

# Selecionando a sequência
x <- bnrf1hvs

# Criando uma série indicadora para Citosina (C = 2)
# Isso nos permite ver a concentração de C ao longo do gene
c_indicador <- ifelse(x == 2, 1, 0)

# Plotagem da série indicadora (primeiros 500 pares de base)
plot(c_indicador[1:500], type = "h", main = "Indicador de Citosina (HVS) - Primeiros 500 bp",

2.3 Espectrograma de Janela Deslizante

Para repetir a análise do Exemplo VII.17, calculamos a densidade espectral em janelas móveis para identificar mudanças na periodicidade da sequência.

# Função para calcular a proporção de GC em janelas (Proxy para análise dinâmica)
window_size <- 100
step <- 50
n <- length(x)
positions <- seq(1, n - window_size, by = step)

# Cálculo da proporção de GC (G=3, C=2) ao longo do gene
gc_content <- sapply(positions, function(p) {
  window <- x[p:(p + window_size)]
  sum(window == 2 | window == 3) / window_size
})

# Gráfico da variação do conteúdo GC no Herpesvírus Saimiri
plot(positions, gc_content, type = "l", col = "darkgreen", lwd = 2,
     main = "Análise Dinâmica do Conteúdo GC - Gene BNRF1 (HVS)",
     xlab = "Posição no Gene (bp)", ylab = "Proporção GC")
abline(h = mean(gc_content), lty = 2, col = "red")
grid()

2.4 Comparação com o Vírus Epstein-Barr (EBV)

No EBV, o gene BNRF1 apresenta picos característicos de periodicidade que indicam regiões codificantes ou estruturais específicas. Ao observar o Herpesvírus Saimiri (HVS):

Similaridade

  • Ambos apresentam variações locais no conteúdo GC, sugerindo uma organização modular do gene.

Diferença

  • O nível médio de GC e a amplitude das oscilações no HVS podem diferir do EBV, refletindo adaptações evolutivas distintas entre os dois herpesvírus.

Questão 3: Decomposição Espectral (Casos de Rubéola)

Esta análise visa identificar padrões periódicos na série temporal de casos de rubéola em Copenhague utilizando a densidade espectral.

3.1 Carregamento e Visualização

library(ggplot2)
library(astsa)

# Leitura dos dados
dados <- read.csv("https://math.mcmaster.ca/~bolker/eeid/2010/Ecology/Copenhagen.csv")

# Criando a série temporal
rubella_ts <- ts(dados$Rubella, start = dados$Date.3[1], frequency = 52)

# TRATAMENTO: Removendo valores NA para permitir o cálculo do espectro
# Substituímos NAs pela média da série para não interromper a continuidade
rubella_ts[is.na(rubella_ts)] <- mean(rubella_ts, na.rm = TRUE)

# Gráfico da série tratada
plot(rubella_ts, main = "Casos de Rubéola em Copenhague (Tratada)", 
     ylab = "Casos", xlab = "Ano", col = "#2c3e50")
grid()

3.2 Cálculo do Espectro

Calculamos o periodograma para identificar as frequências dominantes. Utilizaremos uma suavização (spans) para obter uma estimativa mais consistente da densidade espectral.

# Agora o mvspec funcionará sem o erro de valores em falta
espectro <- mvspec(rubella_ts, spans = c(5, 5), taper = 0.1, log = "no")
## Bandwidth: 0.687 | Degrees of Freedom: 11.36 | split taper: 10%

# Identificando a frequência de pico
frequencia_pico <- espectro$freq[which.max(espectro$spec)]
periodo_pico <- 1 / frequencia_pico

cat("Frequência dominante:", frequencia_pico, "\n")
## Frequência dominante: 4.333333
cat("Período correspondente (em anos):", periodo_pico, "\n")
## Período correspondente (em anos): 0.2307692

3.3 Identificação de Padrões Periódicos

# Plotando o espectro com destaque para o pico principal
plot(espectro, main = "Densidade Espectral - Rubéola", xlab = "Frequência (ciclos/ano)")
abline(v = frequencia_pico, col = "red", lty = 2)
text(frequencia_pico + 0.1, max(espectro$spec), 
     labels = paste("Ciclo de", round(periodo_pico, 2), "anos"), col = "red")
